# 🛒 Automated Amazon & Flipkart Loot Deals Bot

An autonomous, 24x7 Python bot that monitors real-time price drops, loot discounts (50%-90% OFF), generates instant affiliate/profit links, and publishes attractive posts with high-res photos and interactive Buy Now buttons to Telegram channels.

---

## ✨ Features
- ⚡ **Zero-API-Key Deal Aggregator:** Live deals from Indian e-commerce giants (Amazon, Flipkart, Myntra, etc.).
- 🏷️ **Intelligent Affiliate Injection:** Strips vendor tracking and dynamically attaches your Amazon Associate tag or EarnKaro profit links.
- 🖼️ **Rich Telegram Posts:** Sends high-res product photos, bold price comparisons (Deal Price vs MRP), discount badges, and interactive inline buttons.
- 🛡️ **Deduplication Engine:** SQLite database ensures no deal is posted twice.
- 🕒 **Autopilot Scheduler:** Runs continuously in the background at configurable intervals (e.g., every 15 minutes).
- 🖱️ **1-Click Launchers:** Windows `.bat` launchers for testing, verifying connection, and running 24x7.

---

## 🚀 Quick Start
1. Edit [.env](file:///c:/Users/user/Desktop/EARN/.env) with your Telegram Bot Token & Channel username.
2. Double-click [test_deals.bat](file:///c:/Users/user/Desktop/EARN/test_deals.bat) to preview live deals.
3. Double-click [start_bot.bat](file:///c:/Users/user/Desktop/EARN/start_bot.bat) to launch the bot 24x7.
